## 2026-11-09 — ответы заказчика, старт макета

- Рабочее имя: **CSKATICKET** (только для макета; см. оговорку в `ПРАВА.md` про название клуба).
- Оплата: несколько провайдеров (ЮKassa, CloudPayments, Т-Банк, Robokassa) + СБП → в API делаем
  интерфейс `PaymentProvider` с адаптерами; в макете — мок-провайдер без реальных платежей.
- RIGHTS-001 (ЦСКА): логотип, фото арены, схема трибун, афиши — предварительно, для макета
  отделу маркетинга. Документ, срок и файлы — позже.
- Реквизиты продавца, оферта, возврат — заглушки `[…]`.
- Места и цены — из API партнёра → интерфейс `InventorySource`; в макете — мок-источник.
- Сервисный сбор — как в референсе: цена на витрине включает услуги сервиса, плюс раскладка
  «билет + сервис» в подсказке места и корзине.
- Макет: Astro, статическая сборка, npm workspaces (pnpm не установлен); можно выложить на
  GitHub Pages. Прод — позже на сервере в РФ (152-ФЗ: ПДн покупателей хранятся в России).
- Репозиторий: `git init` локально; удалённый репо на GitHub создаёт заказчик (gh CLI нет).

## 2026-11-09 — макет v2: «вау» и один HTML-файл

- Заказчик: нужен открытый репозиторий на GitHub и HTML-файл для показа; приоритет — визуал,
  анимации, своя интерактивная доска выбора места.
- Макет переведён в одностраничное приложение (hash-маршруты + View Transitions API).
  `npm run release` упаковывает всё в `release/cskaticket-demo.html` (~120 КБ, открывается
  двойным кликом). Тот же файл публикует workflow GitHub Pages. Прод-витрина позже — SSR
  (SEO, schema.org) из тех же модулей `lib/`.
- Доска выбора мест: 3D-наклон чаши на общем плане → погружение в сектор с «всплытием» мест,
  карточка сектора при наведении, миникарта, ценовые уровни-фильтры, подбор мест рядом.
- «Вид с места» — перспективная проекция по геометрии арены (код, без фото и без прав).
- Масштаб колесом — только с Ctrl/⌘ (иначе страница «застревает» на схеме при прокрутке).
- Главная: кинетический заголовок, табло обратного отсчёта (реальное время до матча),
  генеративная обложка матча вместо афиши партнёра, 3D-арена, анимированные карточки.
- Оформление: билеты-корешки, кольцо таймера брони, финал с «печатью» билетов и конфетти.
- Открытый вопрос: публичный репозиторий/Pages = публичный адрес, а RIGHTS-001 пока разрешает
  только внутренний показ. Название «ЦСКА» в имени витрины — подтвердить у партнёра.

## 2026-11-09 — анонс-заставка и админка (маркетинг одобрил макет)

- Анонс матча при входе на сайт (~4,6 с, стиль спортивного эфира): шторка клубных цветов,
  влёт команд, удар с кольцом и искрами, шайба, дата, «билеты в продаже», уход шторкой.
  Один раз за визит (sessionStorage), пропуск кнопкой/Esc/кликом/прокруткой, без автозапуска при
  reduced-motion, повтор — кнопка «Смотреть анонс матча». Матч — со страницы или ближайший.
- Админка MVP (`apps/admin`, демо-данные): плитки KPI с динамикой, визиты по дням по витринам,
  воронка visit→paid, источники, устройства, топ матчей; заказы с поиском, фильтром статуса,
  выгрузкой CSV; сравнение витрин с колонкой прав; журнал. Роли: «Аналитик» не видит контакты
  и не выгружает. Светлая/тёмная тема. Палитра графиков проверена валидатором (обе темы).
- `npm run release` теперь собирает и `release/cskaticket-admin-demo.html`.
- Дальше по плану: API (Fastify) + PostgreSQL — события трекера и заказы вместо демо-данных,
  адаптеры эквайринга; витрина переходит с мок-инвентаря на API партнёра.
