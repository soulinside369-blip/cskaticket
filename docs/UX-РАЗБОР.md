# UX-разбор референса: cska.ticket.hockey

Дата: 2026-11-09. Цель — понять, как устроен путь «найти матч → выбрать место», и решить, где
наш продукт будет **удобнее**. Не копируем вёрстку, тексты, графику и код; берём только выводы
о юзабилити. Смотрели главную, страницу матча (`/cska-sibir`), схему арены и сектор 213.

## 1. Как устроен путь сейчас

1. **Главная.** Лента «скоро на льду» (3 ближайших матча), хиро с ближайшим матчем и обратным
   отсчётом, лента дат на весь сезон (24 матча), фильтры «На выходных» / «Избранное», карточки
   матчей «от N ₽», блоки VIP / кешбэк / новости / FAQ.
2. **Матч.** Шапка (соперники, дата, время, арена с адресом), «от 1 300 ₽», избранное, календарь,
   «позвать друзей». Ниже — подбор соседних мест («сколько вас» + диапазон цены, под капчей).
3. **Схема.** Чипы 8 ценовых уровней над схемой; схема с цветными секторами; справа список
   секторов («201 · 97 мест · от 4 100 ₽»), синхронизирован со схемой. Блок «вид с сектора».
4. **Сектор.** Отдельный экран сетки мест (ряд × место), легенда: доступно / выбрано / временно
   занято / недоступно; зум кнопками +/– и жестом; при входе всплывает подсказка про зум.
5. **Корзина.** Боковая панель «Ваши билеты»; приписка, что цена включает услуги сервиса.
6. **Подвал.** Дисклеймер «независимый билетный агент, не официальный сайт клуба», оферта,
   политика, возврат.

## 2. Что работает хорошо — сохраняем как идею (реализация своя)

- Цена «от N ₽» видна уже в карточке матча — человек сразу понимает порядок цен.
- Лента дат по сезону + фильтр «на выходных» — быстрый выбор, когда дата важнее соперника.
- Схема и список секторов синхронизированы; в списке — свободные места и минимальная цена.
- Поиск соседних мест для компании — реальная боль покупателя.
- «Вид с сектора» снимает главный страх «а будет ли видно».
- FAQ про отмену/перенос матча, разницу цены с номиналом, билет в телефоне.
- Дисклеймер о независимом агенте в подвале.

## 3. Где трение — здесь наше преимущество

| # | Наблюдение | Почему мешает | Наше решение |
|---|---|---|---|
| 1 | Выбор места — 2 уровня: сектор → отдельный экран мест | Чтобы сравнить два сектора, нужно входить и выходить; теряется контекст | **Одна схема с плавным зумом**: на общем плане — секторы, при приближении — места прямо в контексте арены. Сравнение без переходов. |
| 2 | Чипы цен — 8 уровней, сопоставление цвет ↔ цена по памяти | Цвета близкие (жёлтый/оранжевый/салатовый), для дальтоников не работает | **Ценовой фильтр-ползунок** + приглушение недоступных по бюджету секторов; на секторе — подпись цены, не только цвет. |
| 3 | Подбор мест рядом — отдельная форма над схемой, под капчей | Результат не показан на схеме сразу; капча на поиске — лишний шаг | **«Лучшие места для N человек»**: выбираю количество и бюджет → система подсвечивает 3 варианта на схеме, один тап — в корзину. Защита от ботов — на брони, а не на поиске. |
| 4 | Подсказка про зум перекрывает сетку мест при каждом входе | Закрывает то, ради чего пришли | Подсказка один раз, в углу, не поверх мест; запоминается. |
| 5 | Список секторов — длинный, без сортировки по выбору пользователя | 25 строк, сложно найти «дёшево и по центру» | Сортировка: цена / вид на лёд / ближе к центру / больше свободных; группировка по ярусам. |
| 6 | Цена «может отличаться от номинала», состав итога виден поздно | Недоверие на последнем шаге — главный риск брошенной корзины | **Прозрачная цена с первого показа**: «билет N ₽ + сервис M ₽ = итого» в подсказке места и в корзине. |
| 7 | Продавец обозначен как «Билетный агент» без юрлица на странице | Покупатель не видит, у кого покупает | **SellerBar** на каждой странице: юрлицо, ИНН, оферта, возврат — одним кликом. |
| 8 | Шапка и логотип сайта — знак клуба и его название как имя сайта | Читается как сайт клуба вопреки дисклеймеру в подвале | В нашем продукте имя витрины = название платформы; знаки клуба — только в слотах по записи `ПРАВА.md`. |
| 9 | Время брони мест не показано | Неясно, сколько у меня времени, «временно занято» без пояснения | Реальный таймер брони с сервера в корзине; у чужих броней — пояснение «освободится, если не оплатят». |
| 10 | Выбор мест с клавиатуры / скринридером не очевиден | Доступность | Навигация по ряду стрелками, озвучка «ряд 5, место 12, 2 700 ₽». |

## 4. Чем будет отличаться наш продукт (формула)

**«От матча до места за 3 касания»:**
1. Матч (карточка с реальной минимальной ценой и наличием).
2. «Сколько вас и какой бюджет» → схема сразу показывает подходящие места и 3 лучших варианта.
3. Тап по варианту → корзина с прозрачным итогом и таймером брони → оплата у провайдера.

Ручной выбор на схеме остаётся для тех, кто хочет конкретное место — с плавным зумом,
фильтром по цене и видом с сектора в подсказке.
