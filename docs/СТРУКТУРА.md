# Структура репозитория (предложение, этап 1)

Монорепо: pnpm workspaces + Turborepo, TypeScript везде (общие типы между витриной, API и админкой).

```
ticket-platform/
├─ apps/
│  ├─ storefront/        Astro (SSR) — движок витрины; одна сборка обслуживает все домены,
│  │                     сайт определяется по Host → site config → тема
│  │  ├─ src/pages/      афиша, /[event], /cart, /checkout, /order/[id], /legal/*
│  │  ├─ src/components/ SellerBar, EventCard, VenueMap, PartyFinder, Cart … (острова React/Preact
│  │  │                  только там, где нужна интерактивность: схема, корзина)
│  │  └─ src/lib/        резолв сайта по домену, Schema.org Event, клиент API
│  ├─ admin/             React + Vite SPA за авторизацией: дашборд по витринам, заказы,
│  │                     воронка, сравнение витрин, роли owner / manager / analyst, журнал действий
│  └─ api/               Node (Fastify): события, места, брони (hold с TTL), заказы,
│                        вебхук провайдера оплат, приём событий аналитики, отчёты
├─ packages/
│  ├─ theme/             токены core/semantic, пресеты сайтов, сборка CSS-переменных,
│  │                     проверка контраста, процедурные паттерны (ice, grass, parquet…)
│  ├─ ui/                общие примитивы (Button, Input, Sheet…) на токенах — для витрины и админки
│  ├─ venue/             формат схем арен (SVG + JSON мест), генератор, подбор соседних мест
│  ├─ analytics/         клиентский трекер (visit → view_event → select_seat → checkout_start →
│  │                     lead/paid, site_id + utm_*) и схемы событий для API
│  ├─ db/                схема PostgreSQL (Drizzle), миграции, сиды демо-данных
│  └─ config/            tsconfig, eslint, prettier
├─ data/
│  └─ sites/             <site>.json: домен, партнёр, пресет темы, реквизиты продавца,
│                        счётчики, ссылка на RIGHTS-xxx
├─ docs/                 ТЗ, ПРАВА, ЖУРНАЛ, UX-РАЗБОР, СТРУКТУРА
├─ DESIGN.md
└─ CLAUDE.md
```

## Ключевые решения

- **Одна сборка витрины на все домены.** Новая витрина = запись в `data/sites` + пресет темы, без
  нового деплоя кода.
- **Брони на сервере.** Hold места с TTL в PostgreSQL (`SELECT … FOR UPDATE SKIP LOCKED`), без
  этого нельзя честно показывать «временно занято» и таймер.
- **Оплата только через провайдера.** API создаёт платёж, витрина делает редирект/виджет, статус
  приходит вебхуком → заказ → админка + уведомления.
- **Проверка прав в CI.** Скрипт сверяет слоты бренд-материалов во всех `data/sites/*.json`
  с реестром `docs/ПРАВА.md` (действующий срок) и проверяет наличие реквизитов продавца.
- **Аналитика своя.** Эндпоинт `POST /collect` → таблица событий → агрегаты для админки.
  Внешние счётчики — опционально, по согласию на cookie.
