# Реестр разрешений партнёров

Без действующей записи бренд-материал на витрину не ставится (вместо него — заглушка `[…]`).
Формат записи: партнёр · что разрешено · где можно использовать · срок · чем подтверждено · файлы.

---

## RIGHTS-001 — ХК ЦСКА (макет для отдела маркетинга)

| Поле | Значение |
|---|---|
| Партнёр | ХК ЦСКА — `[юрлицо и контакт — заполнить]` |
| Разрешено | логотип, фото арены, схема трибун, афиши |
| Где | **только макет для внутреннего показа отделу маркетинга**: закрытый демо-адрес, `noindex`, без приёма реальных оплат |
| Срок | `[…]` |
| Чем подтверждено | `[документ/письмо — приложить]` (со слов заказчика, 2026-11-09) |
| Файлы материалов | `[…]` — ждём от партнёра; с чужих сайтов не берём |
| Название «ЦСКА» в имени витрины/домена | `[подтвердить отдельно]` — сейчас используется рабочее имя CSKATICKET только в макете |

**Статус:** предварительная запись. До появления документа и файлов витрина рендерит слоты логотипа,
фото и афиш как заглушки; схему трибун рисуем своей SVG-реализацией.
Перед публичным запуском: заполнить срок и основание, приложить файлы, получить подтверждение
на использование названия клуба в имени сайта/домена.
