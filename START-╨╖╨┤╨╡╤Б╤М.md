# Старт нового окна — инструкция для заказчика

Этот комплект готов к переносу в новое окно/проект. Порядок действий ниже.

## Файлы в комплекте

- `CLAUDE.md` — правила и состояние проекта. Ассистент читает его в начале каждой сессии.
- `docs/ПРАВА.md` — реестр разрешений партнёров. Без записи бренд-материалы не используются.
- `docs/ТЗ.md` — стартовое техзадание, поля `[…]` заполняете вы.
- `docs/ЖУРНАЛ.md` — создаст ассистент; туда пишутся решения.

## Что сделать вам поэтапно

1. **Создайте новый проект** (отдельное окно/чат), чтобы он не смешивался с КЛЮЧ и Shark Group.
2. **Положите файлы в проект:** `CLAUDE.md` в корень, папку `docs/` рядом. Если проект на GitHub —
   добавьте их в репозиторий.
3. **Заполните минимум в `docs/ТЗ.md`:** название платформы, провайдер оплат, первый партнёр/событие.
4. **Внесите первое разрешение в `docs/ПРАВА.md`** (RIGHTS-001): партнёр, документ-основание, что
   разрешено, срок. Без этой записи ассистент не поставит на витрину логотипы/фото партнёра.
5. **Подключите коннекторы, которые есть:** GitHub (репозиторий), позже — эквайринг, Telegram/email.
   Ассистент проверит, что коннектор доступен; если нет — скажет.
6. **Отправьте ассистенту стартовое сообщение** (готовый текст — ниже).

## Стартовое сообщение для нового ассистента (скопировать в первое сообщение)

> Это новый проект — билетная платформа. Прочитай `CLAUDE.md` и `docs/ТЗ.md`, `docs/ПРАВА.md`.
> Мы делаем движок и тематические витрины для продажи билетов на спорт, работаем официально по
> разрешениям партнёров из `ПРАВА.md`, продавец на витрине обозначается честно, чужие сайты не
> копируем. Начни с этапа 1 из ТЗ: предложи дизайн-систему витрины (DESIGN.md) и структуру движка.
> Задай мне недостающие вопросы из раздела 13 ТЗ, прежде чем писать код.

## Что ассистент сделает дальше

- Соберёт `DESIGN.md` (дизайн-система витрины) и предложит структуру репозитория.
- По мере готовности: движок витрины (афиша → место → чекаут на демо-данных), затем оплата, админка,
  аналитика.
- Будет вести `docs/ЖУРНАЛ.md` и держать `CLAUDE.md` в актуальном виде.

## Граница, которую ассистент держит (и это защищает вас)

- Витрина не выдаёт себя за официальный сайт клуба; всегда видно, кто продавец.
- Бренд-материалы — только по записи в `ПРАВА.md`.
- Чужой сайт не клонируется; делаем свою реализацию по согласованным материалам.
