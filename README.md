# CSKATICKET — макет билетной витрины

Кликабельный макет витрины для продажи билетов на домашние матчи: афиша → матч → интерактивная
3D-схема арены с «видом с места» → корзина → оплата (демо) → электронный билет.

> **Демо-макет для согласования.** Матчи, места и цены — тестовые, оплата не проводится.
> Сайт не является официальным сайтом клуба, лиги или арены. Бренд-материалы партнёра
> (логотип, фото арены, афиши) на макете заменены заглушками до получения файлов и
> подтверждения прав — см. `docs/ПРАВА.md`.

## Посмотреть

- **Одним файлом:** откройте [`release/cskaticket-demo.html`](release/cskaticket-demo.html) в браузере
  (двойной клик; для шрифтов нужен интернет).
- **GitHub Pages:** после включения Pages (Settings → Pages → Source: GitHub Actions) макет
  публикуется автоматически при каждом push в `main`.

## Что внутри

- **3D-схема арены** — чаша с наклоном, плавное погружение в сектор, места прямо на схеме,
  миникарта, клавиатурная навигация.
- **Вид с места** — смоделированный кодом вид на лёд из любого сектора и ряда (не фотография).
- **Подбор мест рядом** — «сколько вас + бюджет» → три варианта на схеме, один тап до корзины.
- **Прозрачная цена** — «билет + сервис = итого» при выборе места и в корзине.
- **Честный продавец** — блок продавца на каждой странице, документы, дисклеймер.
- Анимированные переходы между экранами (View Transitions), кинетическая типографика,
  процедурная графика «лёд», `prefers-reduced-motion` уважается.

## Разработка

```bash
npm install
npm run dev       # http://localhost:4321
npm run release   # сборка + упаковка в release/cskaticket-demo.html
```
